About NLPShield

NLPShield is an AI-powered text analysis platform designed to identify toxic content and potential cybersecurity threats in text. It combines Natural Language Processing, Machine Learning, Retrieval-Augmented Generation and cybersecurity knowledge to produce an interpretable security analysis.

NLPShield v1.0

System Architecture

Core Features

☣️

Toxicity Detection

Detects potentially toxic or abusive text using a trained classification model.

🚨

Cyber Threat Detection

Identifies suspicious text associated with phishing, scams, credential theft and malware.

📚

RAG Knowledge

Retrieves relevant cybersecurity guidance from the local knowledge base.

🧠

AI Explanation

Provides a human-readable explanation of the analysis result.

📈

Confidence Score

Displays model confidence to help interpret classification results.

🗄️

Analysis History

Stores previous analysis results in the local SQLite database.
