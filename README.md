# NLPShield

NLPShield is an AI/NLP-based defensive cybersecurity text analysis system.

## Features

- Toxicity and abusive-language detection
- Cyber-threat detection
- Phishing detection
- Scam detection
- Credential-theft detection
- Malware-related text detection
- Risk classification
- Confidence scores
- RAG-based cybersecurity guidance
- Optional local LLM explanation using Ollama
- Analysis history
- Dashboard
- SQLite database
- Security reports
- FastAPI backend
- HTML/CSS/JavaScript frontend

## Technology Stack

### Backend
- Python
- FastAPI
- Uvicorn
- SQLite
- Scikit-learn
- Joblib

### NLP / Machine Learning
- Text preprocessing
- TF-IDF
- Logistic Regression
- Synthetic/demo training datasets

### RAG
- Local TF-IDF based retrieval
- Local cybersecurity knowledge base

### Optional LLM
- Ollama
- Local Llama model

### Frontend
- HTML
- CSS
- JavaScript
